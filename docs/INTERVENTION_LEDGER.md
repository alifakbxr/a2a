A2A intervention ledger (#13). Run: node scripts/intervention-ledger.mjs transcript.jsonl. Outputs per-call step, tool name, result classification, next observed planner step, timestamp and output byte count. Ignores tool payloads, command arguments, paths and model text. A successful a2a_impact call is not evidence that A2A caused a better app; exact marginal impact requires ablations with equal prompts, model/settings, independent quality tests and provider token accounting. Ambiguous multi-tool steps are marked incomplete, not credited. Reference: https://antigravity.google/docs/cli/headless/ and controlled AB evaluation docs.
