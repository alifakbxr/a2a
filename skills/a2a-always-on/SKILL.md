# A2A Always-On Mode

When triggered via `/a2a-always-on` or when the user asks to enable Always-On:
1. Run the command:
   ```bash
   node ~/.gemini/config/plugins/a2a/scripts/a2a.mjs mode always-on
   ```
2. Confirm to the user that A2A is now in **`always-on`** mode.
