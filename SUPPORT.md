# Support

## Before opening an issue

- Read the [README](README.md), [documentation index](docs/README.md), [compatibility notes](docs/COMPATIBILITY.md), and [build status](BUILD_STATUS.md).
- Check existing [issues](https://github.com/alifakbxr/pilah/issues) for known problems.
- From a source checkout, run `node scripts/pilah.mjs doctor --public`. For installed CLI troubleshooting, try `pilah doctor --public`. Review and redact output before sharing.
- For Antigravity integration issues, follow [host validation](docs/HOST_VALIDATION.md). Distinguish plugin installation, MCP availability, and actual agent tool invocation.

Open a bug report for reproducible defects, a feature request for enhancements, or a blank issue for a focused usage question. Include version, OS, Node version, host surface and version, and a minimal reproduction when relevant. Never upload unredacted transcripts, environment variables, project secrets, or personal information.

For vulnerabilities, follow the [security policy](SECURITY.md). For community concerns, follow the [code of conduct](CODE_OF_CONDUCT.md).

PILAH is a community-maintained open-source project. Support is best effort; no guaranteed response time or service-level agreement is offered.
